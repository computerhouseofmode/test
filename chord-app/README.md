# コード進行ラボ

コード進行を入力すると、その場で再生しながら分析できるブラウザアプリです。
ビルド不要・依存ライブラリなし（Web Audio API で音を鳴らします）。

## 使い方

`chord-app/index.html` をブラウザで開くだけです。

- **入力**: `C Am F G` のようにスペース区切りで1コード＝1小節。
  `| Dm7 G7 | CM7 |` のように `|` で区切ると1小節に複数コードを入れられます。
  `%` は直前のコードの繰り返し、`N.C.` は休み。分数コード（`C/E`）にも対応。
- **再生**: BPM・音色（ピアノ／エレピ／パッド）・奏法（白玉／4分刻み／アルペジオ）・ループ・クリックを切り替え可能。スペースキーで再生／停止。
- **コードをクリック**: そのコードを試聴し、再生開始位置に設定。
- **移調**: ±1 半音ボタン。

## 分析機能

- キーの自動推定（手動指定も可）
- 度数表記（ディグリーネーム）と機能（T / SD / D）
- セカンダリー・ドミナント、裏コード、パッシング・ディミニッシュ、同主調からの借用、ナポリの和音の判定
- ツーファイブ（ワン）の検出
- 定番進行の検出（王道進行、カノン進行、丸サ進行、小室進行、50年代進行 など）
- 終止形（ドミナント終止、サブドミナント終止、偽終止、半終止）
- 発音中のボイシングを鍵盤に表示（前のコードからの動きが最小になるよう自動ボイシング）
- キーのダイアトニック・コード一覧（クリックで試聴、ダブルクリックで追加）
